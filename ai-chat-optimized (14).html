Attachments
Images are sent to a vision-capable model as-is (your main model if it supports images, otherwise the Image model from the Connection tab). Text-like files (.txt, .md, .csv, .json, code) are included as text. Other file types (PDF, Word, Excel) are attached by name only — their content isn't extracted in-browser.
